# Бинарная классификация доходов (>50K)

## Описание работы:

В задачах кредитного скоринга и предсказания дефолта самым важным признаком служит заработная плата клиента. Но не всегда она известна.

Требуется решить задачу бинарной классификации, а именно построить алгоритм, определяющий, превысит ли средний заработок человека порог $50k.

## Какой кейс решаем?

Построить модель машинного обучения, которая на основе характеристик человека будет предсказывать, превышает ли его доход порог в $50,000 в год.
